# 🌿 Parque Nacional Calilegua - Dashboard Climático & Serie Temporal

Se trata de una aplicación interactiva desarrollada en **Streamlit** y **Python** para el análisis de datos meteorológicos históricos (Open-Meteo) en el bioma de las Yungas (Jujuy, Argentina). Se trata de una aplicación que realizo con especial ilusión ya que he trabajado como voluntario junto a los guardaparques allí.


🚀 **[Probar la aplicación interactiva en vivo en Streamlit Cloud](https://calilegua-climate-dashboard-xsw3n7rki6si5pnkhlnxln.streamlit.app/)**

## 📊 Características
- **Ingesta de datos mediante API REST** de Open-Meteo.
- **Tratamiento de series temporales** con Pandas (agregación horaria/diaria, suavizado por media móvil).
- **Visualizaciones interactivas** con Plotly (matrices térmicas, distribución estacional y eventos extremos).

## 🛠️ Tecnologías utilizadas
- Python 3.10+
- Streamlit
- Pandas
- NumPy
- Plotly
